Your agent's facts have an expiration date.

agent-fill checks the date before your agent answers — so it stops serving year-old statistics, cached prices, and dead software versions as if they were current.

Fetch SKILL.md from agent-fill and run its five steps before answering anything time-sensitive.

The gap this closes

without agent-fill

"Odisha's 2026 agricultural statistics show a 4% rise in rice yield." — confident, sourceless, and the 2026 data doesn't exist yet.

with agent-fill

"2026 data isn't published yet (typical lag: 12 months). Latest available: the 2024–25 cycle, released late 2025." — honest, dated, checkable.

Five steps, run in order

  1. AnchorRead the real UTC clock, plus an optional local timezone. Never trust the model's belief about "today."
  2. PriorPass info_type and period explicitly. Look up min and typical lag plus canonical_registries. cannot_exist stops the fetch and cites official registries; may_exist and should_exist proceed.
  3. FetchResolve exact primary URLs (JSON APIs, official registries) over public http/https. Keep published, modified, data-as-of, and accessed dates separate.
  4. ScoreRate the source date against that type's lag window. A future date is unverifiable. Scoring on the published date is an upper bound.
  5. CiteEmit Contract A (inline stamp + clickable Provenance footer with block_number for on-chain state) or Contract B (gap response with canonical registry links).

Install

git clone https://github.com/Nkovaturient/agent-fill.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/agent-fill" ~/.claude/skills/agent-fill

# Optional: register MCP server in Claude Code
claude mcp add agent-fill -- \
  "$(pwd)/agent-fill/mcp_server/.venv/bin/python" \
  "$(pwd)/agent-fill/mcp_server/server.py"
mkdir -p .cursor/skills
ln -s /abs/path/to/agent-fill .cursor/skills/agent-fill

# .cursor/mcp.json
{
  "mcpServers": {
    "agent-fill": {
      "command": "/abs/path/to/agent-fill/mcp_server/.venv/bin/python",
      "args": ["/abs/path/to/agent-fill/mcp_server/server.py"]
    }
  }
}
python3 -m venv mcp_server/.venv
mcp_server/.venv/bin/pip install -r mcp_server/requirements.txt
mcp_server/.venv/bin/python mcp_server/server.py

# Pinned: mcp==1.9.4, pydantic<2.10 (mcp 2.x renamed FastMCP)
# 7 tools: run_pipeline, anchor_date, check_temporal_prior,
# fetch_source, score_staleness, make_provenance, reconcile_sources
pip install -r requirements.txt

python scripts/pipeline.py \
  --query "What is the latest version of requests?" \
  --info-type software_version \
  --url "https://pypi.org/pypi/requests/json"

python scripts/anchor_date.py --tz Asia/Kolkata
python scripts/lag_prior.py --query "Odisha agri stats 2026" \
  --date 2026-11-24 --info-type government_statistics --period 2026
python scripts/staleness_score.py --data-date 2025-03-01 \
  --current-date 2026-11-24 --info-type government_statistics --date-basis data_as_of
python scripts/provenance.py --source "RBI DBIE" \
  --url "https://data.rbi.org.in" --data-date 2025-03-01 --verdict stale --date-basis data_as_of

python evals/run_evals.py  # 15/15 gate, fetch & pressure evals
