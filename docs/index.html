Why Temporal Grounding Matters

Stop serving year-old facts as “current.”

Most AI tools confuse when an article was posted with when the data was actually collected—or invent numbers for reports that haven’t been released yet.

Without agent-fill

“Odisha’s 2026 agricultural statistics show a 4.2% rise in kharif rice yield across coastal districts.”

Failure mode: Confident, sourceless, and impossible—state agricultural statistics have a 6–12 month publication lag. The 2026 statistical abstract does not exist yet.
With agent-fill

“2026 data cannot exist yet (typical lag: 12 months). Latest verified release: 2024–25 cycle, published late 2025.”

Contract B triggered: Halts premature hallucination, cites official registries (MoSPI & DES Odisha), and stamps the nearest valid cycle.

Questions & Architecture

Frequently Asked Questions

What is the difference between the SKILL.md symlink and the MCP server?

SKILL.md teaches the agent the 5-step decision protocol, output contracts (Contract A & B), and anti-rationalization rules. The stdio MCP server (agent-fill-mcp) gives the agent 7 deterministic tools so it never has to guess dates, lag windows, or HTML metadata extraction.

Why does agent-fill separate four different dates on every fetched URL?

A blog post published in November 2026 might cite census data as of 2011. By separating published_date, modified_date, data_as_of_date, and accessed_date, staleness_score.py scores the underlying data currency—and marks the verdict as an upper bound if only a publication date is found.

Does agent-fill require paid API keys or external proxy servers?

Zero API keys required. It runs 100% locally over public HTTPS endpoints with built-in SSRF protection (blocking private/loopback ranges and validating every redirect hop).

How is agent-fill integrated into NASA BlueGram?

BlueGram’s FastAPI backend bridges staleness_score and build_provenance into GET /api/planetary-intel, attaching live temporalGrounding badges and clickable provenance footers to Synoptic Nowcasts, Microsoft Planetary Computer STAC granules, and ISRO ground station telemetry.
